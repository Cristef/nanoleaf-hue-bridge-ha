# Changelog

- Add local discovery with authenticated bridge identity verification.
- Handle mixed IPv4/IPv6 discovery announcements.
- Add downloadable diagnostics without URLs, tokens or profile names.

- Document compatibility with Nanoleaf Hue Bridge 4.4.0 and preserve existing entries, entities and automation tokens during upgrades.
